# Petoria — 宠物用品跨境独立站

> **Thoughtful Essentials for Modern Pets**  
> 为现代宠物家庭提供实用、舒适、注重日常体验的宠物生活用品。

**网站地址：** https://pet.lumaclaw.cn/

## 项目简介

**Petoria** 是一个面向海外市场的宠物用品英文独立站展示项目。网站以现代、简洁的电商体验为设计方向，围绕宠物家庭的日常需求组织商品和内容，帮助访客快速浏览商品分类、比较规格并联系商家。

当前网站主要展示面向消费者的商品浏览与咨询体验；页面导航中亦设有 **Trade & Wholesale** 入口，可作为未来拓展批发询盘业务的方向，但不应将其视为已经完整上线的 B2B 采购系统。

## 网站页面与体验

### 首页（Home）

通过品牌主视觉、宠物类型入口、热门商品分类和精选商品模块，帮助访客快速理解品牌定位并发现产品。

### 商品列表（Shop）

以商品卡片组织商品，提供分类筛选、价格范围、材质、尺寸等筛选条件，以及排序和分页浏览功能。

### 商品详情（Product Detail）

通过多图展示、产品说明、规格与使用护理信息呈现商品细节。部分商品页面提供颜色、数量选择，并设置 **WhatsApp 咨询**入口，方便访客围绕具体商品沟通。

### 品牌与支持信息

网站导航包含 About、Support、Collections 等入口，页脚展示与配送、常见问题、质量安全及批发相关的栏目信息。各入口的实际完成度仍需逐项验收。

## 设计理念

- **简约现代：** 通过清晰的内容层级和留白突出商品本身。
- **宠物生活方式：** 围绕宠物与主人共同生活的场景展示产品。
- **英文优先：** 主要面向海外访客提供英文浏览体验。
- **移动端友好：** 将响应式布局和触控交互作为上线验收重点。
- **重视产品信息：** 用真实图片、尺寸、材质及使用说明帮助用户做出判断。

## 当前状态

> **演示 / 开发阶段**

从当前公开页面可见，网站已经具备商品浏览和咨询入口等前台展示能力；但页面明确提示社交资料与商店服务尚未接通，订阅表单为本地演示表单，**不会实际发送邮件**。

因此，现阶段不能宣称网站已具备真实订单支付、邮件营销、物流履约、会员系统或完整的批发交易流程。网站中有关全球配送、客户数量及质量保证的宣传信息，在正式商用前也应以实际业务和可验证资料为准。

## 建议的下一步建设方向

1. **完善交易链路：** 明确采用在线零售结账，还是以询盘为主的 B2B 模式；接入相应的购物车、支付或报价表单。
2. **完善询盘管理：** 为 WhatsApp、电子邮件和批发询盘建立可靠的客户信息收集与跟进流程。
3. **夯实商品数据：** 核对价格、库存、材质、规格、起订量、图片授权及合规说明。
4. **实施 SEO：** 为分类页和详情页设置独立标题、描述、规范链接、站点地图及适用的商品结构化数据。
5. **增加信任要素：** 补充真实的企业信息、联系方式、配送政策、退换货条款及隐私政策。
6. **提升性能与体验：** 检查移动端适配、图片加载速度、筛选交互和核心网页指标。
7. **扩展 B2B 能力：** 如以批发业务为目标，可加入 MOQ、OEM/ODM、阶梯报价、样品申请和采购询盘功能。
